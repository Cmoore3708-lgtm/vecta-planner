VECTA NATIVE WEBSITE BOOKING — SETUP

1. Upload this complete build to the existing GitHub/Vercel Workshop Pro project.
2. In Supabase, open SQL Editor and run WEBSITE-BOOKING-MIGRATION.sql once.
3. Verify the public booking page at:
   https://YOUR-VERCEL-ADDRESS.vercel.app/booking
4. In Fasthosts, edit the Embed block and paste:

<iframe
  src="https://YOUR-VERCEL-ADDRESS.vercel.app/booking"
  title="Vecta Motors online booking"
  width="100%"
  height="1050"
  style="width:100%;border:0;display:block;"
  loading="eager">
</iframe>

5. Publish the Fasthosts website only after testing a submission.
6. In Workshop Pro, use the top menu and select Website Requests.
7. Open a request, select date/technician/time/hours/cost, then click
   Confirm booking & prepare email. This creates the allocated planner job and
   opens a completed confirmation email in the computer's email application.

IMPORTANT
- The Google Form remains untouched until the new route is tested.
- Automatic background email sending is not enabled yet. The current release
  prepares the complete email for review and sending, avoiding accidental confirmations.
