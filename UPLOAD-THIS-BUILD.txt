VECTA Workshop Pro V41.25 — SMALL DEPLOYMENT BUILD

Upload the CONTENTS of this folder to the root of the existing GitHub repository.
No npm install or manual build is required. index.html is the live application.

After Vercel deploys, press Ctrl+F5 once.

Changes in this build:
- Fleet Manager always opens on all individual work due in the next 30 days.
- Each due MOT, service, tax item and six-month safety check appears as its own row, sorted earliest first.
- Vehicles is renamed Total vehicles and moved alongside the fleet category boxes.
- Nissan Internal is displayed as NMUK Internal.
- Nissan Pool Cars is displayed as NMUK pool cars.
- Fleet category boxes are narrower.
- Top due boxes use the same MOT, SER, TAX and 6 mo colour system as the list badges.
- Contractor end-of-month invoices list every completed job in date order.
- Contractors still have a separate date-ordered downloadable job list.
- NMUK invoices use one consolidated total; the detailed NMUK job list remains separate.
- WPC records remain consolidated under the single name WPC.
