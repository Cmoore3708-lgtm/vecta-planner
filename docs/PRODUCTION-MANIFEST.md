# VECTA Workshop Pro production inputs

Only the files below are deployment authorities. Amendments must target these sources and pass CI before release.

| Area | Authoritative source |
|---|---|
| Main Workshop Pro application | `index.html` |
| Public booking page | `booking.html` and `public/booking.html` |
| Shared browser rules | `public/js/vecta-*-rules.js` |
| Offline worker and PWA shell | `service-worker.js`, `public/service-worker.js`, `public/manifest.webmanifest`, `public/icons/` |
| Server functions | `api/*.js` |
| Database safeguards | `supabase/*.sql` |
| Fleet seed data | root Fleet data scripts loaded by `index.html` |
| Logos used at runtime | `assets/vecta-logo.webp`, `assets/vecta-logo.png`, `assets/vecta-header.png` |
| Hosting routes and cron | `vercel.json` |
| Automated release protection | `tests/`, `.github/workflows/vecta-io-regression-guard.yml` |

`dist/` is generated by `npm run build` and is never edited or committed. Historical copied application trees under `assets/`, `css/` and `dist/` are not production sources.
