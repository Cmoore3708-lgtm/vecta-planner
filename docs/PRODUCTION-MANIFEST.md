# VECTA Workshop Pro production inputs

Only the files below are deployment authorities. Amendments must target these sources and pass CI before release.

| Area | Authoritative source |
|---|---|
| Main Workshop Pro application | `index.html` |
| Public booking page | `public/booking.html` |
| Shared browser rules | `public/js/vecta-*-rules.js` |
| Offline worker and PWA shell | `public/service-worker.js`, `public/manifest.webmanifest`, `public/icons/` |
| Server functions | `api/*.js` |
| Database safeguards | `supabase/*.sql` |
| Logos used at runtime | `public/assets/vecta-header.png` plus the main shell's embedded print logo |
| Hosting routes and cron | `vercel.json` |
| Automated release protection | `tests/`, `.github/workflows/vecta-io-regression-guard.yml` |

`dist/` is generated by `npm run build` and is never edited or committed. Historical root application copies, copied API handlers, generated files and duplicated public assets are not production sources and have been removed from this branch.
